# C64 samples

Curated demos for c64m. Core set is tracked; local scratch can be gitignored like `samples/apple2/`.

## assembly/

C64 assembly-language samples for the in-emulator assembler / debugger:

| File | Notes |
|------|--------|
| `c64-life-bas.asm` | Conway's Game of Life (text mode, BASIC stub entry) |
| `ripple-c000.asm` | Hires bitmap ripple effect at `$C000` |
